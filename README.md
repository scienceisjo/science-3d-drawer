# 과학 3D 자료 서랍

다른 기관과 선생님들이 만든 웹 3D 과학 자료로 가는 링크 모음입니다. 자료마다 라이선스, 근거 페이지, 수업에서 쓰는 법, 출처 문구를 적었습니다.

- 사이트: https://scienceisjo.github.io/science-3d-drawer/
- 목록 파일(AI·도구가 읽는 용도): https://scienceisjo.github.io/science-3d-drawer/resources.json

## 저작권

- 이 저장소와 사이트에는 **링크만** 있습니다. 다른 사이트의 화면·그림·3D 파일·코드를 복사해 두지 않았고 미리보기 그림도 넣지 않았습니다.
- 각 자료의 저작권은 그 자료를 만든 기관·사람에게 있습니다. 자료 이름과 로고도 그분들 것입니다.
- 라이선스 정보는 자료마다 적힌 「확인」 날짜에 원래 페이지에서 본 내용입니다. 바뀔 수 있으니 쓰기 전에 원래 페이지의 안내를 다시 확인해 주세요. 이 정리는 법률 자문이 아닙니다.
- 이 사이트의 설명 글과 화면 짜임: 제작 : 과학을 사랑하는 선생님 · © 2026 · All rights reserved.
- 라이선스 정보가 틀렸으면 이슈로 알려 주세요. 고치거나 목록에서 빼겠습니다.

## 쓰는 법 네 가지

| 표시 | 뜻 |
|---|---|
| 고쳐 써도 됨 | CC BY·CC BY-SA·MIT·CC0 같은 공개 라이선스. 출처를 밝히면 퍼가기·고쳐 쓰기가 됩니다(SA는 같은 라이선스로, NC는 비영리로만). |
| 퍼가기 허용 | 만든 곳이 공식 퍼가기(iframe) 방식이나 허락 문구를 내놓았습니다. 그 방식대로만 넣습니다. |
| 링크로만 | 공개 라이선스가 없거나 퍼가기가 막혀 있습니다. 새 창 링크만 겁니다. |
| 자료마다 다름 | 한 사이트 안에서도 모형마다 라이선스가 다릅니다. 모형 페이지의 조건을 따릅니다. |

## 자료 더하기

1. `resources.json` 의 `items` 에 한 칸을 더합니다(칸 이름은 다른 항목과 같게).
2. 저장소 루트에서 `python _src/build.py` → `index.html` 이 다시 만들어집니다(빠진 칸·링크로만인데 iframe 표시 같은 실수를 잡습니다).
3. 커밋·푸시하면 GitHub Pages 에 반영됩니다.
