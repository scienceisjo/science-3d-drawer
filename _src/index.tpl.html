과학 3D 자료 서랍

다른 기관과 선생님들이 만든 웹 3D 과학 자료로 가는 링크를 모았습니다. 자료마다 저작권과 수업에서 쓰는 법을 적었습니다.

최종 확인 · 자료 개

저작권 안내

  1. 이 사이트에는 링크만 있습니다. 다른 사이트의 화면·그림·3D 파일·코드를 복사해 두지 않았고, 미리보기 그림도 넣지 않았습니다.
  2. 각 자료의 저작권은 만든 기관·사람에게 있습니다. 자료 이름과 로고도 그분들 것입니다.
  3. 라이선스는 아래 「확인」 날짜에 원래 페이지에서 본 내용입니다. 바뀔 수 있으니 쓰기 전에 원래 페이지의 안내를 한 번 더 봐 주세요. 이 정리는 법률 자문이 아닙니다.
  4. 수업 자료에 넣을 때는 자료마다 적힌 출처 문구를 함께 적어 주세요(「출처 문구 복사」 단추).
  5. 이 사이트의 설명 글과 화면 짜임은 이 사이트를 만든 사람에게 저작권이 있습니다. 라이선스 정보가 틀렸으면 GitHub 이슈로 알려 주세요. 고치거나 목록에서 빼겠습니다.

강의 화면을 AI로 만들 때는 목록 파일 주소 resources.json 을 함께 주면, AI가 자료마다 쓰는 법을 읽고 그대로 따릅니다.
